# Requisitos provisórios

Os requisitos abaixo representam o escopo inicial do sistema e poderão ser revisados durante a Etapa 1.

| Código | Requisito funcional | Situação |
| --- | --- | --- |
| RF01 | O sistema deve permitir cadastrar um chamado. | Provisório |
| RF02 | O sistema deve permitir listar os chamados cadastrados. | Provisório |
| RF03 | O sistema deve permitir editar um chamado. | Provisório |
| RF04 | O sistema deve permitir excluir um chamado. | Provisório |
| RF05 | O sistema deve permitir pesquisar chamados. | Provisório |
| RF06 | O sistema deve permitir atribuir prioridade Baixa, Média ou Alta a um chamado. | Provisório |
| RF07 | O sistema deve permitir alterar o status de um chamado entre Aberto, Em atendimento e Resolvido. | Provisório |
| RF08 | O sistema deve permitir filtrar chamados. | Provisório |

## Observações para validação

- Definir quais campos serão obrigatórios no cadastro.
- Definir os critérios e campos da pesquisa.
- Definir quais filtros estarão disponíveis.
- Confirmar as regras para edição e exclusão.
