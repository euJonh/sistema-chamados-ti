# Registro de decisões

Decisões relevantes sobre escopo, tecnologias e organização do projeto devem ser registradas nesta página.

| Data | Decisão | Motivo | Participantes |
| --- | --- | --- | --- |
| A definir | Uso de HTML, CSS, JavaScript e LocalStorage na primeira versão | Manter o escopo compatível com a proposta inicial do projeto | Equipe do projeto |

## Como registrar

Adicione uma linha sempre que o grupo tomar uma decisão que possa influenciar o desenvolvimento. Registre o contexto de forma breve e informe quem participou da decisão.
